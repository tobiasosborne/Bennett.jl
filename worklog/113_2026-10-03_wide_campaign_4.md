under active_{K+1}); after the loop `vw[d] = held[d]`. Pure loops get no extra gates (empty hold

**Bennett-08xz — throw-helper drop matched user functions by name** (a2d296d). The U15 allowlist in
`src/extract/instructions.jl` dropped a call on callee-name prefix alone (`j_throw_`, `ijl_throw`,
`jl_throw`, `ijl_bounds_error`, `jl_bounds_error`). Julia mangles user `throw_foo` as `j_throw_foo_N`,
so an unregistered user call was silently deleted: a used value became `resolve!: undefined SSA
variable`; an effect-only call vanished and the circuit answered at x == 42 where Julia throws.
From Julia only `j_throw_` can collide with a user name; from `.ll` all five can (red for 7 names,
both forms). IR facts (Julia 1.12, both optimize modes): every genuine helper carries `noreturn` on
its declaration (`ijl_throw`, `ijl_bounds_error_int`, `j_throw_inexacterror_N`, `_boundserror_N`,
`_overflowerr_binaryop_N`, `_complex_domainerror_N`); `ijl_*` has no call-site attribute, so the
declaration must be checked; at optimize=false a `j_throw_*` call is not always followed by
`unreachable`. Rule now: dropped only when the name matches AND the call provably cannot return
(`noreturn` on the call site or the callee declaration, or `unreachable` as the next instruction;
`_is_noreturn_call`, `_is_runtime_throw_call`, `_RUNTIME_THROW_PREFIXES`). The `unreachable` arm is
needed for test_3vf2's hand-written fixtures (attribute-less `@ijl_throw`; 6 tests failed without
it). A prefix match that can return takes the normal path: registered -> inlined, else the loud U15
error. The same rule is applied in `_vec_vm_is_skel_callee` (`vector_vm_walk.jl`); no test pins that
path. test_7q9z's witness `throw_7q9z` had relied on the bug and was renamed `q7_sq`: it now checks
the unregistered compile fails loud naming `q7_sq` and compiles after `register_callee!`; stale-cache
invalidation is pinned only by the cache-identity testsets (header comment says so). New
`test/test_08xz_throw_prefix_user_fn.jl`: `throw_x` / `throw_` / `Throw_x` as value, in a branch,
